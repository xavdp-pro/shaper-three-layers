# Shaper Workspace — Human Foundations
## The work environment that follows the organization, not the computer

## 1. The simple idea

Shaper Workspace is the environment in which you work with the organization.

It can run above Windows, macOS or Linux. The underlying computer still handles screens, drivers, sound and specialist native software.

Shaper handles the work context.

## 2. You do not need to learn the cathedral

A normal user mainly sees:

- Workspace;
- Spaces;
- People;
- Agents;
- Files;
- Apps;
- Search.

Everything else exists to make those simple concepts reliable.

## 3. Context before application

Instead of thinking:

> “Which software contains the thing I need?”

Shaper tries to let you think:

> “I am working on ACME.”

From the ACME context you can reach documents, people, orders, messages, tasks, decisions and agents.

## 4. Files still exist

You can browse files and folders. The difference is that Shaper can also understand their relationships and content.

You can search by filename or ask a contextual question such as:

> “Find the contract with the automatic renewal clause and show the related correspondence.”

## 5. Importing from your computer

You choose a file. Shaper imports it through a controlled gateway. After that, normal work can happen inside the Shaper context rather than relying on a random file on someone's Desktop folder.

## 6. Using specialist software

Shaper does not try to replace every creative or engineering application.

A video project can be opened in a specialist native editor when authorized, then brought back into Shaper as a new governed version.

## 7. The Web

You may see web pages inside a controlled Web Surface, but the browser is not the center of the environment.

The Web can be:

- a knowledge source for agents;
- an original source you inspect;
- an external service you interact with.

Upload, download and clipboard crossings can be controlled.

## 8. Agents

You can speak or type naturally to agents. The same rules that limit your access also limit what the agent may do on your behalf.

The agent should be able to explain what it did and why it cannot do something.

## 9. Multiple screens

Shaper is designed for real desktop work. Contexts and surfaces can be arranged across several monitors and remapped when the physical setup changes.

## 10. Moving to another computer

The goal is:

```text
install → enroll → authenticate → recover your authorized Workspace
```

You should not rebuild the company's working context because the hardware changed.

## 11. Offline

Depending on company policy, you may have no local copy beyond small caches, a protected offline working set, or a full sovereign local system.

The Workspace should make it clear when data is stale/offline and when synchronization is complete.

## 12. Human control

Automation is not mandatory. The maturity path can be:

```text
manual → assisted → delegated → approved automation → trusted automation → periodic review
```

You can remain manual where that is the right choice.

## Success

The Workspace succeeds when it feels less like switching between unrelated products and more like entering the living context of the organization.
